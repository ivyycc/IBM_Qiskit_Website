# IBM Qiskit Event Website

## Overview

This website was created to showcase the IBM Qiskit 2025 event at Wits University. It provides visitors with information about the event, including speakers, schedule, and registration details.

Built with **React** and styled for responsiveness across devices.

## Features

* **Speaker and Organizer Profiles**: Each speaker has a photo, and a bio. Organizers have a photo and social media links.
* **Event Schedule**: A clear timeline of sessions and activities.
* **Responsive Design**: Works on both desktop and mobile devices.
* **Interactive Elements**: Hover effects, clickable speaker cards, and smooth animations for better user experience.
* **Qiskit Integration**: Optional code snippets or demonstrations can be embedded to show Qiskit concepts live.

## Tech Stack

* **Frontend**: React, JavaScript, Tailwaind
* **APIs in backend**: Google Maps API (for event locations)
* **Deployment**: Vercel
* **Version Control**: Git / GitHub
